# announcement_image_dropbox

Drop the next announcement hero image here. Tim renames it to
`announcement-assets/<version>-hero.<ext>`, wires `banner.imageURL`, and moves the
previous active hero to `announcement_image_archive/`. Empty at a new announcement
= revert to the logo hero.

Image spec: slim banner ~4.5:1, ~1620x360px, PNG or JPEG.
