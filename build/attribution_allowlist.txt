# Allowlist for the attribution gate (build/attribution_gate.py, POS-W113).
#
# A word on this list may be the subject of an attribution phrase such as
# "confirmed by X" or "per X" without failing the build. Manufacturer and brand
# names are NOT listed here: they are derived from the manufacturer and brand
# fields of the shards, so a new brand never needs an entry.
#
# Rules for this file:
#   - One word per line. Case, accents and a trailing possessive are ignored.
#   - Public sources, retailers, ordinary words and document words only.
#   - NEVER add a real person's name. If a flagged subject is a person, fix the
#     text (use a role such as "the project owner") instead of adding it here.
#   - Adding a term is a visible diff in a PR. The PR description lists each
#     term added.
#   - Months that double as given names (April, May, June, August, mei, juni)
#     are deliberately not listed.
